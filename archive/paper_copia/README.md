## How to view the article

No LaTeX is installed on this machine, so use one of these:

### Option A — Overleaf (easiest, nothing to install)
1. Go to <https://www.overleaf.com> and create a free account.
2. New Project -> Upload Project, and upload the **whole `paper/` folder**
   (it already contains `manuscript.tex`, `refs.bib` and `figures/` with the
   8 PNGs).
3. Set `manuscript.tex` as the main document and press **Recompile**.
   Overleaf ships with `elsarticle`, so it compiles as-is.

### Option B — Local install
1. Install **MiKTeX** (<https://miktex.org/download>) or TeX Live.
2. From the `paper/` folder run:
   ```
   pdflatex manuscript
   bibtex   manuscript
   pdflatex manuscript
   pdflatex manuscript
   ```
   The figures are found via `\graphicspath{{../}{./}{figures/}}`.

## Regenerating the figures (titles removed)

`savefig300.m` now strips the in-figure title (journals put it in the caption).
Re-generate the figures so they have no titles, then collect them:

```matlab
silhouette_variation        % fig_base_vs_optimized, fig_shape_modes  (instant)
compare_parameterizations   % parameterization_comparison            (instant)
sensitivity_analysis        % fig_sensitivity_tornado                (~2 min)
compare_algorithms(150)     % fig_algo_convergence, fig_algo_exploration
run_multiobjective          % fig_pareto_front
regen_optimum_spectrum      % fig_spectrum_hardcon  (2 evals, no re-optimization)
collect_figures             % copy the 8 final PNGs into paper/figures/
```

## Comparison references

Key prior studies using the same fast (XFOIL/Amiet-class) framework, for the
literature comparison in Table 1 of the manuscript:

- **Kou et al. (2023)**, *Expert Systems with Applications* 217:119513 —
  same framework (co-author L. Botero-Bolívar); NACA0012 baseline, CST vs VAE,
  PSO; reductions 1.11 dBA (CST) and 1.75 dBA (VAE). arXiv:2210.00101.
- **Volkmer & Carolus (2018)**, AIAA 2018-3130 — XFOIL + Amiet + evolutionary.
- **Lee et al. (2013)**, *J. Mech. Sci. Technol.* 27(2) — GA, wind-tunnel validated.
- **Rodrigues & Marta (2014)**, *Struct. Multidiscip. Optim.* 50 — blade-level.
- **Ricks et al. (2020)**, *AIAA Journal* — RANS WPS + Amiet.
- **Tahani et al. (2012)**, *Energy* 44(1) — small wind-turbine airfoils.
- Reference code: github.com/lauraboterob/WindTurbine_Noise_prediction
